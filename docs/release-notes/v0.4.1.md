# topo v0.4.1

This security patch updates TLS dependencies used by the CLI and desktop app and pins the Node.js version used for deployment tools.

- Update rustls to 0.23.46, rustls-webpki to 0.103.16, and webpki-roots/webpki-root-certs to 1.0.10. These address RUSTSEC-2026-0346 through 0349 and 0381 through 0383, including distrusted emSign certificate paths.
- Use Node.js 24.22.1 for Wrangler, incorporating the October 21 security fixes.
- Include the graph-query correctness and performance fixes merged since v0.4.0.

Existing workspaces, settings, TLS trust configuration, and database schema remain compatible. This release does not need a D1 migration or a Workers compatibility-date change.

Download the installer or CLI archive for your platform and verify it against `SHA256SUMS`. The macOS and Windows installers retain the existing signing limitations described in the installation documentation.

既存のワークスペース・設定はそのまま利用できます。CLI・デスクトップアプリの TLS 依存を更新するセキュリティ修正版です。
