# topo v0.2.1

Adds a Windows GUI installer and fixes macOS GUI packaging that could produce a “damaged app” warning in v0.2.0.

- Sign the completed `topo.app` bundle ad hoc and verify its resource seal before packaging.
- Replace macOS GUI `.tar.gz` downloads with Apple Silicon and Intel `.pkg` installers that install and upgrade `/Applications/topo.app`.
- Verify the app after extracting each installer payload; include both installers in SHA256 checksums and build provenance.
- Add a layered Liquid Glass icon with a clearer enclosure rim, compiled by Apple’s Icon Composer/Xcode tools; retain the original topo mark.
- Add a Windows x64 setup executable with a Start menu shortcut, optional desktop shortcut, in-place upgrades and uninstall support. Installation is per user and does not require administrator privileges.
- Preserve existing workspaces and user configuration. The CLI is a separate download.

## macOS installation / インストール

Download the `.pkg` matching your Mac: `aarch64-apple-darwin` for Apple Silicon,
`x86_64-apple-darwin` for Intel. Run the installer, then open topo from Applications.

Macに合う`.pkg`をダウンロードしてください。Apple Siliconは`aarch64-apple-darwin`、
Intelは`x86_64-apple-darwin`です。インストール後、アプリケーションからtopoを開きます。

The installer is not Developer ID signed or notarized. macOS may block installation;
allow this installer in System Settings → Privacy & Security → Open Anyway.
Ad hoc signing verifies integrity but does not establish Apple trust; downloaded
`.tar.gz` app copies can still be rejected by Gatekeeper. Prefer the `.pkg` installer.

AppleのDeveloper ID署名・公証はありません。インストーラーがブロックされた場合は、
システム設定 → プライバシーとセキュリティ → このまま開く、で許可してください。
`.tar.gz`から直接取り出したアプリには起動制限が残る場合があるため、`.pkg`を推奨します。

## Windows installation / インストール

Run `topo-gui-v0.2.1-x86_64-pc-windows-msvc-setup.exe`, then open topo from
the Start menu. Settings → Apps can uninstall it; workspaces and settings remain.
The installer is unsigned, so Windows may display a SmartScreen warning.

Windowsでは`topo-gui-v0.2.1-x86_64-pc-windows-msvc-setup.exe`を実行し、
スタートメニューからtopoを開いてください。管理者権限は不要です。
設定 → アプリからアンインストールできます。署名がないためSmartScreenの警告が出る場合があります。
