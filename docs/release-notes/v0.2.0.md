## What's new

- Open and switch repositories from the GUI toolbar, File menu, or Cmd/Ctrl+O. The redesigned chooser separates the current repository, folder action, and recent repositories, and remains usable in small windows.
- Remember the ten most recently opened workspaces and restore the previous target on launch. Initialize a new workspace explicitly; cancellation and failed opens preserve the current editor and drafts.
- Pause background cloud polling while the window is inactive or the repository chooser is open, then synchronize on return. Requests are serialized, unchanged responses avoid redraws, and outages use bounded retry delays with one notification.
- Edit node metadata in the inspector, including priority, assignee, timestamps, and explicit GitHub PR links. CLI filters and cloud operations support the same metadata.

## Downloads

CLI archives are provided for Linux x86_64, Windows x86_64, and macOS Apple Silicon/Intel. Separate macOS GUI archives include `topo.app`. Verify downloaded archives against `SHA256SUMS` before running them.

The macOS app is unsigned and not notarized. See [installation instructions](https://github.com/r4ai/topo/blob/v0.2.0/docs/releasing.md) for details.

## Validation

The release workflow checks the exact tag commit on Linux, Windows, and macOS, smoke-tests each packaged CLI, and publishes only after all checks and builds pass. Repository selection and synchronization also received rendered Linux X11 QA, including a narrow window and a live cloud update after minimizing/restoring the GUI. Native folder dialogs on macOS/Windows have not received manual device QA.
