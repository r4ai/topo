# topo v0.2.0 Release Notes

## What's New

- **Repository Switcher**: Open and switch workspaces directly from the GUI toolbar, menu, or `Cmd/Ctrl+O` with recent folder history and inline initialization
- **Background Sync Optimization**: Automatically pause cloud polling while the GUI window is inactive or the repository chooser is open, coalescing sync on window focus
- **Node Metadata & Pull Requests**: Edit priorities, assignees, and pull request links from the inspector panel and CLI; creation, update, and completion timestamps are shown read-only
- **Performance Improvements**: Cached derived graph layout, single-pass multi-selection traversal, and dynamic canvas grid spacing

## Downloads

Prebuilt CLI archives are available for Linux x86_64, Windows x86_64, and macOS (Apple Silicon / Intel). Separate macOS GUI archives include `topo.app`, which is unsigned and not notarized in this release; v0.2.1 replaces them with `.pkg` installers. Verify all downloaded archives against `SHA256SUMS`.

See [Installation & Releasing Guide](https://github.com/r4ai/topo/blob/main/docs/releasing.md) for details.
