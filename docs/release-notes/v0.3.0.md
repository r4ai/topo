# topo v0.3.0

A redesigned desktop app: a new design system with light and dark themes, a glass window, and a rebuilt repository switcher. The GUI also gains view modes, a notes editor and faster canvas and server paths.

## Design system and themes

- New look: neutral surfaces and text, with a small fixed set of signal colours. Blue marks selection, focus, in-progress work and links; amber marks the critical path, milestones and high priority; green marks done and ready; red, amber and green alarms mark overdue, unsaved and saved states.
- Themes: System (follows the OS live), Light and Dark. Switch from the toolbar theme menu or View > Appearance. The choice is saved per user.
- Monotone option: turns every signal colour neutral and keeps only the alarms. Off by default.
- Glass window: on macOS the window background is blurred and the titlebar is merged into the toolbar; on Windows 11 the window uses Mica. Palettes, pills, toasts and dialogs are drawn as glass surfaces.
- The toolbar no longer overlaps in a narrow window: the repository name truncates and the statistics give way first.
- Experimental: on macOS 26, `TOPO_GLASS=1` backs the window with AppKit's Liquid Glass material.

## Repository switcher

- The repository chooser is now a palette: type to filter recent repositories or paste a path, move with ↑↓, open with Enter, close with Esc.
- ⌘O opens the folder picker; ⌘⌫ forgets a recent repository.
- Rows show cloud-linked workspaces and folders that no longer exist.
- A folder without a workspace offers to initialize one in place.

## Canvas and editing

- View modes: hide done and dropped nodes, group nodes by tag, and dim nodes below a priority.
- A selected node's edges are drawn across tag bands.
- A Markdown notes editor in the inspector.
- Faster canvas frames and fewer server requests.

## Notes for upgrading / アップグレード時の注意

Existing workspaces and settings are kept. The theme starts as System.

既存のワークスペースと設定はそのまま引き継がれます。テーマの初期値は「System」（OS の外観に追従）です。ツールバーのテーマメニューか「View > Appearance」から Light / Dark / モノトーンに切り替えられます。

## Installation / インストール

Download the installer for your platform from the assets below and verify it against `SHA256SUMS`. The macOS `.pkg` and the Windows setup executable are not signed by Apple or Microsoft; see [macOS installation](https://github.com/r4ai/topo/blob/main/docs/macos-install.md) if the installer is blocked.

お使いの環境に合うインストーラーを下のアセットからダウンロードしてください。macOS の `.pkg` と Windows のセットアップは署名されていないため、ブロックされた場合は上記リンクの手順で許可してください。
